새 캐릭터는 built-in image_gen 도구로 제작한 투명 PNG 동작 시트입니다.

각 시트는 6열 × 5행 30칸입니다. 왼쪽부터 오른쪽으로 읽습니다.

| 번호 | 동작 |
|---|---|
| 0 | 기본 서기 |
| 1–4 | 오른쪽 걷기 4단계 (왼쪽은 런타임 미러) |
| 5–8 | 앉기·수면·기지개·점프 |
| 9–14 | 넘어짐·회복 6단계 |
| 15–20 | 만두 먹기 6단계 |
| 21–26 | 잡혔을 때 버둥거림·뚱한 표정 |
| 27–29 | 캐릭터 전용 행동 3단계 |

알파 연결 영역으로 본체와 떨어진 효과선을 구분하고, 실제 얼굴·몸통을 기준으로 런타임 몸집과 중심을 맞춥니다. 보통 크기의 몸집 기준은 약 76 논리 픽셀이며 귀·꼬리·갈기는 자연스럽게 튀어나옵니다. 발끝은 공통 바닥 기준에 고정합니다. 새 친구는 현재 친구의 크기 설정을 이어받습니다.
그림은 팬 프로젝트용 AI 생성 연출이며 공식 원화가 아닙니다. 캐릭터의 권리는 원권리자에게 있습니다.
