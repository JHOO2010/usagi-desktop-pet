# 먼작귀 펫

Windows 작업표시줄 위를 산책하는 비공식 먼작귀 데스크톱 펫입니다. 우사기·치이카와·하치와레·모몽가·쿠리만쥬·랏코·시사를 지원합니다. 화면 끝을 걸어나가면 반대편에서 다시 등장합니다.

## 설치

[Releases](https://github.com/JHOO2010/usagi-desktop-pet/releases)에서 최신 `UsagiPet-Setup-버전.exe`를 내려받아 설치하세요. Windows 10/11, .NET Framework 4.x 환경에서 실행합니다. 관리자 권한 없이 사용자 계정에 설치되며 시작 메뉴 바로가기를 만듭니다.

## 캐릭터

| 캐릭터 | 전용 행동 | 먹거리 |
|---|---|---|
| 우사기 | 폴짝·우사기 랩 | 피자만두 |
| 치이카와 | 조심스러운 산책·수줍은 인사 | 푸딩 |
| 하치와레 | 밝은 인사·흥얼거리기 | 케첩 파스타 |
| 모몽가 | 꼬리와 장난·짧은 활공 | 고기만두 |
| 쿠리만쥬 | 느긋한 산책·한 모금 | 연어 육포 |
| 랏코 | 당당한 산책·검술 연습 | 슈크림 |
| 시사 | 꾸벅 인사·작은 서빙 동작 | 사타판빈 |

먹거리는 원작·공식 상품에서 확인되는 음식 또는 취향을 바탕으로 고른 앱의 간식입니다. 모두 공식 최애 음식이라는 뜻은 아닙니다. 캐릭터별 말투·성격·음식의 근거와 각색 범위는 [캐릭터 자료](docs/CHARACTERS.md)를 참고하세요.

캐릭터마다 걷기·수면·넘어짐·먹기·드래그 시트를 가지며 서로 다른 캐릭터끼리도 기존 상호작용을 공유합니다. 전용 행동·한국어 말풍선은 팬 프로젝트용 연출입니다. 원작 음성의 짧은 발췌와 공용 카툰 수면 효과음을 사용하며 [출처](sounds/SOURCES.txt)를 포함합니다.

기존 설치의 AppId·설치 경로·실행파일명·시작앱 등록과 저장 설정은 유지합니다. 이름은 먼작귀 펫으로 바뀌며, 실행파일명 `우사기.exe`와 GitHub 저장소 주소는 업데이트 호환성을 위해 유지합니다.

## 조작

- 한 번 클릭: 폴짝 / 두 번: 하트 / 세 번 이상: 하트 폭발
- 드래그: 다른 위치로 옮기기. 버둥거리다가 2.5초 넘게 잡고 있으면 뚱한 표정으로 바뀝니다.
- 머리 위에서 마우스를 부드럽게 움직이기: 눈을 감고 좋아하기
- 가까이에서 마우스 흔들기: 쳐다보기와 고개 갸웃
- 우클릭 → 우사기 랩 🎤: 지정 영상의 14초 발췌로 공연. 근처 우사기들도 모여 박자를 타며, 랩 그만하기로 종료합니다. 클릭·드래그·먹이 주기로도 중단할 수 있습니다.
- 우사기 랩은 포함된 기본 음원으로 실행합니다. 음원 변경 기능은 제공하지 않습니다. 효과음 출력 모드가 랩에도 적용됩니다.
- 우클릭 → 먹거리 주기: 현재 캐릭터의 음식이 놓이며 같은 먹거리의 가까운 친구들이 쫓고 먼저 잡은 한 마리만 먹기
- 설정 → 캐릭터: 현재 친구를 일곱 캐릭터 중 하나로 변경. 선택 화면에는 캐릭터 선택만 표시합니다.
- 우사기 외 캐릭터의 우클릭 메뉴에는 수줍은 인사·흥얼거리기·활공·한 모금·검술·꾸벅 인사 등 해당 친구의 행동을 표시합니다.
- 우클릭 → 친구 추가…: 원하는 캐릭터를 한 마리씩 추가 (현재 크기 설정 유지, 최대 16마리)
- 친구들 정리: 추가 친구를 닫고 원본만 남기기. 원본의 모두 종료는 전부 닫습니다.
- 원본 캐릭터 선택은 저장하며, 추가 친구들은 다음 실행에 복원하지 않습니다.
- 트레이에는 각 친구의 캐릭터 얼굴과 이름을 표시합니다. 설정창 로고도 현재 선택한 친구의 모습으로 즉시 바뀝니다. 설치파일·바로가기의 공통 앱 아이콘은 유지합니다.
- 우클릭: 쉬기, 쓰다듬기, 먹이, 랩, 복제/정리, 설정, 종료
- 설정 창: 크기, 3단 효과음 출력, 시작 시 실행, 업데이트, 정보 (화면 이동은 모니터가 여러 개일 때만 표시)
- 10초 동안 마우스를 움직이지 않으면 졸기 시작하며 움직이면 깨어납니다.

복제 우사기들은 마주치면 서로 인사하고, 작은 우사기는 큰 우사기 뒤로 줄지어 걷습니다. 커서를 근처에서 움직이면 다가왔다 도망가는 장난을 하며, 먼저 잠든 우사기가 있으면 옆으로 모여 잠듭니다. 클릭·드래그·먹이 주기가 우선합니다.

넘어지는 우사기 옆에서는 다른 우사기가 놀라 폴짝 뜁니다.

걷기 보폭, 가끔 넘어졌다 일어나기, 사라지는 발자국, 밤의 느린 산책, 아침 첫 인사를 포함합니다. 크기·소리·마지막 화면과 위치는 `%LOCALAPPDATA%\UsagiPet\settings.txt`에 저장합니다. 자동 시작은 기본으로 꺼져 있으며, 원본 우사기의 **설정 → 시작 시 실행**으로 Windows 로그인 시 실행을 켜고 끌 수 있습니다. 프로그램을 제거하면 해당 설치 경로의 시작앱 등록도 제거합니다.

효과음은 설정의 **끔 · 이어폰 · 전체**에서 선택합니다. 이어폰은 기본 출력이 이어폰/헤드셋일 때만, 전체는 스피커를 포함한 현재 기본 출력 장치에서 재생합니다. 동시 다중 장치 출력은 아니며 원본 대비 50% 음량을 유지합니다. 기본 산책은 인터넷·AI 연결 없이 실행합니다. 업데이트 확인과 다운로드에는 인터넷 연결이 필요합니다.

## 글라스 UI와 화면 모드

설정의 **화면 모드**에서 라이트·다크·시스템을 선택합니다. 모든 친구가 같은 모드를 사용하며 다음 실행에도 유지합니다. 시스템 모드는 Windows의 앱 밝기 설정을 따릅니다. 선택은 `%LOCALAPPDATA%\UsagiPet\theme.txt`에 저장합니다.

설정과 하위 페이지는 창을 열 때 뒤쪽 화면을 메모리에서 읽어 흐리게 그리는 글라스 표면을 사용합니다. 글자·버튼은 선명하게 유지합니다. 실시간 Acrylic 배경은 아니며 다시 열면 배경이 갱신됩니다. 배경은 파일로 저장하거나 전송하지 않습니다. 화면을 읽을 수 없으면 테마의 단색 표면으로 표시합니다. 우클릭 메뉴와 일반 말풍선도 같은 밝기 모드를 사용합니다.

## 화면 주사율에 맞춘 움직임

산책 중인 모니터의 현재 주사율을 읽어 60Hz에서는 60FPS, 144Hz에서는 144FPS를 목표로 그립니다. 화면 이동 시 바로, 주사율 변경은 약 2초 이내에 다시 확인합니다. 알림 영역 아이콘에 마우스를 올리면 현재 목표 Hz를 볼 수 있습니다.

고해상도 타이머와 공용 스케줄러를 사용하며, 그리기 버퍼를 재사용합니다. 화면 주사율과 관계없이 이동·점프는 경과 시간으로 계산합니다. 실제 FPS는 시스템 부하와 Windows 스케줄링에 따라 달라질 수 있습니다.

## 프로그램 안에서 업데이트

원본의 우클릭 → 설정에서 **밑줄 있는 업데이트 제목**을 누르면 업데이트 화면으로 이동합니다. 버전과 변경 내용을 읽고 업데이트 확인·다운로드·설치를 진행할 수 있습니다. 실행 후 약 12초, 이후 4시간마다 GitHub의 최신 정식 릴리스를 자동으로 확인합니다. 우클릭할 때도 자동 확인하며 1분 이내 반복 요청은 생략합니다. 새 버전이 있으면 알림과 메뉴의 설정 옆에 표시합니다.

**v버전 업데이트 받기 → 다운로드 진행률 → 설치하고 다시 켜기** 순서로 진행합니다. GitHub에서 받은 설치파일은 릴리스의 SHA-256과 비교하고, 기존 우사기를 닫은 후 설치·재실행합니다. 크기·효과음·화면 설정은 유지합니다. 다운로드는 `%LOCALAPPDATA%\UsagiPet\updates`에 보관하며, 연결 실패 시 메뉴에서 재시도할 수 있습니다. Windows 기본 curl로 전송하고 curl이 없으면 .NET HTTP를 사용합니다. 기본 릴리스 경로의 연결 실패 시 GitHub API도 확인합니다. 오류는 `updates\update.log`, 설치 기록은 `updates\install-update.log`, 마지막 설치 결과는 `updates\last-install-result.txt`에 남깁니다.

복제본은 별도로 업데이트를 확인하지 않습니다. 설치 시 복제본은 닫히며, 재실행 후 원본부터 시작합니다.

## 빌드와 검증

Windows PowerShell에서:

```powershell
.\build.ps1
.\check.ps1
.\build-installer.ps1 -Version 1.3.0
```

설치파일 빌드에는 [Inno Setup 6](https://jrsoftware.org/inno-setup/downloads)이 필요합니다. `ISCC.exe`를 PATH에 넣거나 일반 설치 경로 또는 `packaging/inno/`에 두세요.

## 버전별 출시

```powershell
.\release.ps1 -Version 1.4.0 -NotesFile .\release-notes\v1.4.0.md
```

변경 내용을 커밋·푸시한 깨끗한 main 브랜치에서 실행합니다. 빌드와 검증 후 버전 태그, 설치파일, SHA-256 체크섬, 변경 내역을 GitHub Releases 초안에 업로드하고, 모든 파일이 준비되면 최신 정식 릴리스로 공개합니다. 같은 버전을 덮어쓰지 않습니다. GitHub CLI 로그인과 `origin` 연결이 필요합니다.

설정 창의 **정보 보기**에서 제작자 포트폴리오, GitHub 저장소와 권리 안내를 확인할 수 있습니다.

## 권리와 출처

비공식 팬 프로젝트이며 원작자 또는 공식 서비스와 관계없습니다. 캐릭터와 음성의 권리는 각 권리자에게 있습니다. 이미지와 음성, 제공된 온글잎 꾹지체를 포함한 제3자 자료에 오픈소스 라이선스를 부여하지 않습니다. 사용·재배포에는 각 권리자의 조건이 적용됩니다. 음성 출처는 [sounds/SOURCES.txt](sounds/SOURCES.txt)를 참조하세요.

메뉴·정보 창에는 NAVER의 나눔스퀘어라운드(수정하지 않은 원본)를 사용하며 SIL OFL 1.1이 적용됩니다. [글꼴 출처·라이선스 전문](fonts/OFL.txt)을 설치파일에도 포함합니다. 대사 말풍선은 온글잎 꾹지체를 유지합니다.

업데이트 조회는 GitHub 릴리스에 포함된 `update.json`을 캐시 없이 요청하며, 설정에 확인 시각·실패 상태를 표시합니다. 정보 파일이 없는 예전 릴리스에만 GitHub API를 사용합니다.

음성은 앱 전체에서 한 번에 하나만 재생합니다. 같은 소리의 재시작을 막고 직접 클릭한 반응이 자동 음성보다 우선합니다. 캐릭터 크기는 귀·꼬리·갈기를 제외한 머리 폭을 기존 우사기에 맞추며, 새 친구에 임의의 크기를 부여하지 않습니다.

v2.1.0부터 여섯 캐릭터는 `characters/캐릭터/동작.png`의 개별 4프레임 시트 54개를 사용합니다. [생성 프롬프트와 작업 기록](asset-prompts/strips-v2.1-progress.json)을 포함합니다. 우사기 이미지와 음원은 유지합니다.

v2.1.1의 크기 기준은 이미지에서 직접 확인해 기록한 [얼굴 양끝 좌표 216개](characters/face-landmarks.tsv)입니다. 밝은 픽셀이나 그림 전체 너비로 얼굴 크기를 추정하지 않습니다. 기본 크기에서 얼굴 폭은 우사기와 같은 68px이며, 귀·꼬리·갈기·망토·튀어나온 털선은 제외합니다.

새 친구의 소리는 [상황별 연결표](SoundCues.cs)로 구분합니다. 원작 반응은 맞는 상황에 연결하며, 걷기·점프·하트·먹기·소품에는 별도의 비음성 카툰 효과음을 사용합니다. 효과음 생성 코드는 [scripts/generate_action_sfx.py](scripts/generate_action_sfx.py)이며 캐릭터 목소리를 합성하지 않습니다.

업데이트 후 첫 실행에 같은 말풍선 설정창에서 변경 내용을 한 번 표시합니다. 설정의 **변경 내용**에서 현재 버전 또는 발견된 새 버전의 내용을 다시 볼 수 있습니다. GitHub 릴리스 설명과 설치파일의 `release-notes.md`는 동일한 릴리스 문서에서 생성됩니다.

v2.2.0은 앉기·기상·쓰다듬기의 중간 자세를 연결하고, [먹기 시트 수정 기록](asset-prompts/eating-polish-v2.2.json)의 새 그림과 씹기 효과음을 하나의 시간표로 사용합니다. 얼굴 폭 68px는 유지하며 그림을 비율과 다르게 늘리지 않습니다. 승인된 원작 반응 두 개를 추가했고, 새 캐릭터 소리는 발성 구간의 평균 레벨과 최고 레벨을 제한해 재생합니다. 전체 50% 및 이어폰 전용 조건은 유지합니다.
