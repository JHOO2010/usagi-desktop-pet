# 캐릭터 해석과 먹거리 근거

확인일: 2026-11-23. 한국어 말풍선은 성격과 발화 방식을 참고한 **팬 프로젝트용 각색**이며 공식 번역·원작 대사 모음이 아닙니다. 먹거리는 모두를 단 하나의 공식 ‘최애 음식’으로 단정한 목록이 아닙니다. 작품·공식 상품의 연관 음식과, 확인된 취향을 바탕으로 고른 앱의 연출을 구분합니다.

| 캐릭터 | 말투·성격 반영 | 앱에서 주는 음식 | 확인 범위 |
|---|---|---|---|
| 우사기 | 야하·우라 같은 짧은 외침, 활기차고 겁 없는 행동 | 피자만두 | 원작에서 먹는 음식. 야마자키 공식 자료에서 직접 명시 [1] |
| 치이카와 | 조심스럽고 수줍은 반응, 짧은 발성과 감탄 위주 | 푸딩 | 작품 속 푸딩 장면이 확인되는 먹거리. 개인만의 최애라는 뜻은 아님 [2] |
| 하치와레 | 완성된 문장, 호기심·격려·긍정적인 말투 | 케첩 파스타 | 직접 만든 음식으로 야마자키 공식 자료에서 명시 [1] |
| 모몽가 | 귀여움을 내세우는 당당하고 요구하는 말투, 짧은 활공 | 고기만두 | 공식 ‘고기만두 먹는 마스코트’의 연관 음식. 최애 설정의 근거로 쓰지 않음 [3] |

| 랏코 | 침착하고 간결한 격려, 검술 연습과 달콤한 휴식 | 슈크림 | 공식 소개의 **단것을 좋아함**을 바탕으로 고른 앱의 간식. 슈크림이 최애라는 확인은 없음 [5] |
| 시사 | 붙임성 있는 존댓말과 부드럽게 늘이는 어미, 부지런한 인사 | 사타판빈 | 165화의 먹거리. 자색고구마 속을 참고한 오키나와식 튀김 과자 [6] |

## 구현 범위

- 인사, 걷기, 쓰다듬기, 기쁨, 점프, 호기심, 놀람, 잡혔을 때, 먹이 발견, 먹기 시작, 식후, 수면, 기상, 특유 행동을 구분합니다. 자동 말풍선의 7~10초 간격을 유지하며 같은 상황의 직전 문장은 반복하지 않습니다.
- 우클릭 메뉴의 행동 줄이 현재 캐릭터에 맞게 바뀝니다. 우사기는 기존 랩, 다른 친구는 전용 행동을 실행합니다. 캐릭터 선택 화면은 선택과 뒤로가기만 제공합니다.
- 음식 이름, 바닥에 놓이는 소품, 네 컷 먹기 시트를 함께 바꿉니다. 음식이 먹는 도중 다른 종류로 변하지 않도록 **같은 먹거리의 친구끼리** 쟁탈전에 참여합니다.
- 3회의 먹기·씹기·짧은 효과음 시간을 함께 사용합니다. 접시·그릇을 쓰는 캐릭터는 마지막에 빈 그릇을 남깁니다.
- 새 그림의 얼굴 양끝 좌표를 수동으로 검수하고 `characters/face-landmarks.tsv`에 기록합니다. 기본 표시 얼굴 폭은 우사기와 같은 68px이며 귀·꼬리·갈기는 제외합니다.
- 원작 음성 파일을 새로 추가하거나 합성하지 않습니다. 기존에 승인된 음성과 상황별 비음성 효과음을 유지합니다.
