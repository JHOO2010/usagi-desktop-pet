# 더 둥근 글라스 화면과 빠른 캐릭터 선택

- 글라스 배경의 색이 더 은은하게 비치도록 조정했어요.
- 팝오버 모서리는 22px로, 선택 버튼도 더 둥글게 다듬었어요.
- 업데이트 본문의 검은 네모 배경을 주변 표면에 맞췄어요. 안쪽 여백과 둥근 읽기 영역도 정리했어요.
- 어색한 강제 줄바꿈과 줄·문단 간격을 다시 맞췄어요. 문장 폭에 맞춰 단어 단위로 줄을 정리해요.
- 캐릭터 선택창은 전체 동작 이미지 대신 작은 미리보기만 읽어요. 창을 먼저 띄우고 이미지는 비동기로 채워요.
- 같은 PC의 첫 열기 검사에서 창은 39ms, 일곱 미리보기는 316ms에 준비됐어요. 실제 시간은 PC 환경에 따라 달라질 수 있어요.
