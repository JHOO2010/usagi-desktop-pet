# 먼작귀 펫 v2.1.1

- 얼굴 크기 추정 방식을 제거했습니다. 여섯 캐릭터의 216개 프레임을 확인해 얼굴 왼쪽·오른쪽 좌표를 기록하고, 우사기와 같은 기본 얼굴 폭 68px로 맞췄습니다. 귀·꼬리·주황 갈기·망토·튀어나온 털선은 기준에서 제외합니다.
- 점프·쓰다듬기·하트 폭발·좌우 발소리·잠·먹기·넘어짐·드래그·특유 행동을 서로 다른 소리로 연결했습니다. 한 캐릭터 음성을 모든 동작에 재사용하던 방식을 제거했습니다.
- 원작의 먹기·놀람·수면·버둥거림 등 상황이 확인되는 반응을 별도로 연결하고, 이동·점프·하트·소품 동작에는 직접 만든 비음성 카툰 효과음을 사용합니다. 캐릭터 목소리를 합성하거나 음높이만 바꿔 다른 발성으로 만들지 않았습니다.
- 새 캐릭터의 발소리를 실제 걸음 거리에 맞춰 재생합니다. 짧은 효과음도 정상적으로 읽도록 수정했습니다.
- 우사기의 기존 그림·크기·음원, 전체 50% 음량, 이어폰 전용 재생과 동시 음성 방지는 유지합니다.
