프로그램 안에서 GitHub 기반 업데이트를 받을 수 있습니다.

- 실행 약 12초 후와 이후 4시간마다 최신 정식 릴리스를 자동 확인합니다.
- 원본 우사기 우클릭 메뉴에서 **업데이트 확인**을 직접 누를 수도 있습니다.
- **새 버전 업데이트 받기 → 다운로드 진행률 → 설치하고 다시 켜기**로 이어집니다.
- GitHub에 올린 SHA-256과 설치파일을 비교한 뒤 설치하며, 설정을 유지하고 자동으로 재실행합니다.
- 복제본은 중복 확인하지 않고, 설치 시 함께 닫힙니다.
- 연결이나 다운로드 실패 시 산책은 계속되며 메뉴에서 다시 시도할 수 있습니다.

이 버전을 설치한 다음 출시부터 내부 업데이트를 사용할 수 있습니다.

검증: 버전 비교, 시험판/초안 제외, 저장소 고정 주소, 체크섬·실행파일 검증, 변조 거부, 실제 GitHub 다운로드와 메뉴 상태 전환, 기존 기능 회귀.
