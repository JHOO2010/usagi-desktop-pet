# 먼작귀 펫 v2.1.0

- 우사기 외 여섯 캐릭터를 동작별 4프레임 시트 54개로 다시 만들었습니다. 걷기·앉기·수면·기지개·점프·먹기·넘어짐·드래그·특유 행동을 각각 분리했습니다.
- 귀·꼬리·갈기를 제외한 머리 폭을 기존 우사기에 맞추고, 프레임마다 달라지던 크기와 중심을 보정했습니다. 우사기의 기존 그림과 음원은 유지합니다.
- 쿠리만쥬의 귀, 랏코의 이마 흉터, 모몽가의 코와 꼬리, 시사의 눈썹과 옆 갈기 등 캐릭터 특징을 다시 잡았습니다.
- 피자만두가 입에 닿은 채 조금씩 작아지고, 마지막에는 빈손이 되는 먹기 동작을 추가했습니다.
- 여섯 캐릭터의 음원을 교체·재편집했습니다. 여러 화자와 배경음이 섞인 영상 장면 대신 단독 캐릭터의 짧은 공개 미리듣기와 독립 발성을 사용합니다. 공용 음성 채널과 전체 50% 음량을 유지합니다.
- 업데이트 후 첫 실행에 변경 내용을 말풍선 설정창으로 표시합니다. 설정의 ‘변경 내용’에서 다시 볼 수 있습니다.
- GitHub 릴리스 설명과 앱에서 표시하는 변경 내역을 같은 문서로 관리합니다.
