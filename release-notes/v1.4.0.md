넘어짐과 피자만두 먹기를 전용 이미지로 새로 만들었습니다.

- **넘어짐:** 발이 걸림 → 앞으로 넘어짐 → 엎드림 → 주변 살피기 → 몸 일으키기. 좌우 방향을 지원하고 기울인 점프 그림 대신 전용 포즈를 사용합니다.
- **피자만두:** 만두 들기 → 입에 대기 → 베어 먹기 → 씹기 → 마지막 한입 → 만족한 표정.
- 머리 크기와 바닥 기준을 맞췄고, 두 장을 겹쳐 그려 손이나 귀가 중복되는 표현도 피했습니다.
- 손·입·음식을 따로 추가하지 않고 먹는 포즈 안에 포함했습니다.

검증: 새 이미지 RGBA 투명도, 각 시트 6개 프레임 로딩, 단계별 렌더링, 넘어짐/회복 시간과 기존 동작 회귀.
