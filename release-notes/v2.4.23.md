# 연결된 모니터 사이를 오가요

- 높이가 비슷한 좌우 모니터는 경계에서 걸어 넘어가요. 작업표시줄 높이가 조금 다르면 이동 높이를 부드럽게 맞춰요.
- 높이 차이가 크거나 상하로 배치된 화면은 가장자리로 나갔다 다음 화면에서 이어서 등장해요.
- 던진 캐릭터는 실제로 연결된 좌우·상하 경계를 통과해요. 화면이 없는 바깥 방향에서는 되튕겨요.
- 넘어간 화면의 주사율을 따라가고 마지막 화면을 기억해요. 모니터가 분리되면 기본 화면으로 복귀해요.
- 모니터 하나에서는 기존 동작을 유지해요. 좌우·상하·음수 좌표·서로 다른 높이의 가상 배치 검사와 기존 회귀 검사를 통과했어요. 이번 PC에는 모니터가 하나만 연결되어 실제 듀얼 화면 검증은 하지 못했어요.
