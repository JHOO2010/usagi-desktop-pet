# 캐릭터마다 다른 말투와 먹거리

- 캐릭터 선택 화면에서 특유 행동 버튼을 뺐습니다. 이제 우클릭 메뉴에서 현재 친구의 인사·흥얼거리기·활공·한 모금·검술·꾸벅 인사를 바로 실행합니다. 우사기의 랩과 한 번 클릭 점프는 유지합니다.
- 인사·걷기·쓰다듬기·기쁨·점프·호기심·놀람·드래그·먹기·식후·수면·기상·특유 행동의 말풍선을 구분했습니다. 치이카와의 짧은 감탄, 하치와레의 격려, 모몽가의 당당한 요구, 쿠리만쥬의 감탄과 한숨, 랏코의 간결한 말투, 시사의 부드러운 존댓말을 반영했습니다. 한국어 문구는 팬 프로젝트용 각색입니다.
- 먹거리는 우사기 피자만두, 치이카와 푸딩, 하치와레 케첩 파스타, 모몽가 고기만두, 쿠리만쥬 연어 육포, 랏코 슈크림, 시사 사타판빈으로 나눴습니다. 메뉴 이름·바닥 음식·먹기 그림을 함께 바꿉니다.
- 우사기 외 여섯 친구의 먹기 그림을 각각 네 컷으로 수정했습니다. 입에 닿아 줄어드는 음식, 손 두 개, 마지막 삼키기와 빈 그릇·빈손을 확인하고 얼굴 양끝 좌표를 다시 검수했습니다.
- 모든 음식을 공식 최애로 단정하지 않습니다. 작품·공식 상품의 연관 음식과 앱의 간식 선택을 구분하고 GitHub의 `docs/CHARACTERS.md`에 확인 근거를 정리했습니다. 랏코의 슈크림은 확인된 단것 취향을 바탕으로 고른 간식입니다.
- 같은 먹거리의 친구들끼리 쟁탈전에 참여합니다. 다른 종류의 음식이 먹는 도중 피자만두로 바뀌지 않습니다.
- 일어나는 중 인사·커서 장난·쓰다듬기가 끼어드는 문제를 막았습니다. 자동 인사도 말풍선의 7~10초 간격을 지키며, 같은 상황의 직전 문구를 반복하지 않습니다.
- 먹기 계산에 남아 있던 예전 네 번 먹기 시간을 제거하고, 세 번 씹는 그림·효과음과 마지막 한입이 사라지는 시간을 맞췄습니다. 우클릭에서 전용 행동을 선택하면 쉬는 중에도 다시 움직입니다.
- 기존 음성·이어폰 전용 출력·50% 음량과 설치 호환성을 유지합니다. 새 음성을 추가하거나 합성하지 않았습니다.
