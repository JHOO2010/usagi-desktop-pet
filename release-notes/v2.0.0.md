# 먼작귀 펫 v2.0.0

- 앱 이름을 **먼작귀 펫**으로 변경하고 우사기·치이카와·하치와레·모몽가·쿠리만쥬·랏코·시사 7종을 지원합니다.
- 설정 → 캐릭터에서 현재 친구를 바꾸고, 우클릭 → 친구 추가에서 원하는 캐릭터를 다양하게 추가할 수 있습니다.
- 새 캐릭터마다 투명 30칸 동작 시트: 기본·걷기·수면·기지개·점프·넘어짐/회복·먹기·드래그·특유 행동을 추가했습니다.
- 캐릭터별 산책 속도, 팬 연출 대사, 짧은 원작 음성, 전용 행동을 연결했습니다. 치이카와의 수줍은 인사, 하치와레의 흥얼거림, 모몽가의 활공, 쿠리만쥬의 한 모금, 랏코의 검술 연습, 시사의 인사를 볼 수 있습니다.
- 서로 다른 캐릭터끼리 인사·따라 걷기·낮잠·먹이 경쟁·넘어짐에 놀라는 반응을 공유합니다.
- 원본 캐릭터 선택을 저장하고, 알림 영역 아이콘도 캐릭터 얼굴로 바뀝니다.
- 이어폰/헤드셋 전용 음성, 전체 음량 50%, 주사율 대응, 공용 프레임 스케줄러와 업데이트 검증은 유지합니다.
- 기존 설치 AppId·폴더·실행파일명·시작앱·설정·GitHub 업데이트 주소는 호환성을 유지합니다. 새 시작 메뉴 이름은 먼작귀 펫입니다.

이미지: built-in image_gen으로 만든 비공식 팬 연출. [동작 시트와 프롬프트](https://github.com/JHOO2010/usagi-desktop-pet/blob/main/characters/README.md)
음성: 각 캐릭터 원작 음성의 짧은 발췌, [출처 및 가공](https://github.com/JHOO2010/usagi-desktop-pet/blob/main/sounds/SOURCES.txt). 공용 수면 소리는 성우 음성이 아닌 카툰 효과음입니다.
