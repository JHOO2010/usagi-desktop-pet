# 더 편하게 읽고, 부드럽게 조작해요

- 업데이트 본문 위에서도 마우스 휠이 작동해요.
- 제목은 또렷하게, 문단과 목록은 여유 있게 정리했어요.
- 중복된 버전 문구를 빼고 설명 영역을 위로 넓혔어요.
- 업데이트 동작은 하단 중앙의 텍스트 링크로 옮겼어요. 마우스를 올리면 강조돼요.
- 효과음 아래 안내 문구를 없애고 설정 행 간격을 통일했어요.
- 캐릭터 선택 버튼을 ‘캐릭터 바꾸기’로 바꿨어요.
- 정보 보기는 조금 더 은은하게 표시하고 아래 여백을 늘렸어요. 정보 화면의 두 링크 사이 간격도 넓혔어요.
- 시작 시 실행과 효과음 선택이 부드럽게 미끄러져요. 화면 모드·크기 버튼도 선택 상태가 자연스럽게 전환돼요.
