# 먼작귀 펫 v2.2.0

- 여섯 캐릭터의 먹기 시트를 수정했습니다. 만두를 든 세 프레임에서 음식이 입에 닿고, 마지막에는 빈손과 만족한 표정이 되도록 다듬었습니다. 새 그림의 얼굴 양끝 좌표도 다시 기록했습니다.
- 앉았다 걸을 때와 잠에서 깰 때 중간 자세를 거쳐 일어나도록 수정했습니다. 쓰다듬기 반응도 앉는 중간 자세를 사용하며, 얼굴 폭 68px와 발 기준선은 유지합니다.
- 먹기·씹기·효과음을 같은 시간표로 묶었습니다. 세 번의 씹는 반응은 0.72·1.67·2.55초에 맞추고, 삼킨 뒤에는 씹는 모션을 멈춥니다. 긴 공용 씹는 소리가 동작과 따로 재생되던 방식을 제거했습니다.
- 확인된 원작 반응 두 개를 추가했습니다. 치이카와의 놀람은 넘어질 때, 랏코의 큰 반응은 하트 폭발 때 재생합니다. 검수에서 제외된 모몽가·하치와레 후보는 포함하지 않습니다.
- 새 캐릭터 소리에 발성 구간의 평균 레벨과 최고 음량 제한을 적용했습니다. 발소리·수면음은 작게 유지하며, 짧은 효과음과 목소리의 큰 음량 차이를 줄였습니다. 전체 50% 음량, 이어폰 전용 재생, 단일 음성 채널은 유지합니다.
- 중간 자세와 기상 전환, 씹기 시간표, 재생 음량 상한을 검사에 추가했습니다. 원작 목소리의 자연스러움은 청취 확인한 후보에 한해 반영하며, 모든 이어폰에서 동일한 청감을 보장하는 검사는 아닙니다.
