# 설정 정리와 3단 효과음 모드

- 효과음을 **끔 · 이어폰 · 전체**의 3단 선택으로 바꿨습니다. 왼쪽은 완전 무음, 가운데는 이어폰/헤드셋 연결 시에만 재생, 오른쪽은 스피커를 포함한 현재 기본 출력 장치로 재생합니다. 효과음과 랩에 같은 출력 조건을 적용하며 50% 음량은 유지합니다.
- 출력 모드는 다음 실행에도 유지하며 새로 추가하는 친구에게도 복사합니다. 기존의 켜짐 설정은 이어폰 모드로 이어받습니다. 전체에서 이어폰으로 바꾸면 스피커 재생을 즉시 멈추고, 끔으로 바꾸면 진행 중인 소리도 멈춥니다.
- 랩 음원 변경 기능을 제거했습니다. 우사기 랩 공연은 포함된 기본 음원으로 실행합니다.
- 설정의 ‘변경 내용’ 버튼과 업데이트 확인 시간을 없앴습니다. **밑줄 있는 업데이트 제목**을 누르면 같은 말풍선 안의 업데이트 화면으로 이동합니다. 버전·업데이트 확인·다운로드·설치 상태와 변경 내용을 함께 볼 수 있습니다.
- 변경 내용 문서에 베이지 색상의 가늘고 둥근 스크롤바를 적용했습니다. 라이트·다크 모드를 따르며 휠, 드래그, 키보드 스크롤과 텍스트 선택·링크 기능을 유지합니다.
- 제목·캐릭터 로고·닫기 버튼의 기준선을 맞추고 캐릭터 선택 위아래의 여백을 정리했습니다. 400×430px 크기와 말풍선 꼬리는 유지합니다.
- 정보 화면의 스크롤을 없애고 한 화면에 소개·제작자·링크·권리 안내를 배치했습니다. 안내 문구를 줄이고 직접 줄바꿈해 단어가 홀로 다음 줄로 떨어지지 않도록 정리했습니다.
- 화면 모드 아이콘을 단순한 해 모양으로 교체했습니다.
- 3단 출력 조건, 즉시 음소거, 설정 복원, 업데이트 제목 이동과 테마 스크롤 동작을 검사했습니다.
