우사기들의 상호작용 네 가지를 추가했습니다.

- **서로 인사:** 마주치면 잠깐 멈추고, 한 마리가 야하 하면 다른 마리가 답합니다.
- **줄지어 산책:** 작은 우사기들이 큰 우사기 뒤를 크기에 맞는 간격으로 따라갑니다.
- **커서와 장난:** 가까이 움직이는 커서에 다가가 건드리는 듯 멈춘 뒤 반대쪽으로 도망갑니다. 실제 마우스 위치를 변경하지 않습니다.
- **같이 낮잠:** 먼저 잠든 우사기가 있으면 다른 우사기들이 옆으로 모여 잠듭니다.

클릭·드래그·먹이 주기는 자동 행동보다 우선합니다. 상호작용 사이에 쉬는 시간을 두고 같은 화면에서만 모이도록 했습니다.

검증: 인사와 지연 답장, 큰 개체 추종과 이동, 커서 접근/도망, 잠자리 집결/수면, 먹이 주기 시 자동 행동 취소, 기존 동작 회귀.
