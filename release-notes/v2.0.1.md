# 먼작귀 펫 v2.0.1

- 새 친구의 크기를 무작위로 주던 동작을 제거하고 현재 친구의 크기 설정을 이어받도록 수정했습니다.
- 귀·꼬리·갈기를 제외한 몸집을 공통 기준으로 맞추고, 그림 전체 대신 얼굴·몸통 중심을 기준으로 배치합니다.
- 동작 시트의 떨어진 효과선이 크기·발 위치를 바꾸지 않도록 본체 영역을 추출합니다.
- 모몽가의 활공 가속/착지, 랏코의 준비/검술 후 정지, 캐릭터별 인사·리듬·한 모금의 움직임을 분리했습니다.
- 앱 전체가 음성 채널 하나를 공유해 여러 친구의 소리가 동시에 겹치지 않게 했습니다.
- 같은 소리의 반복 시작을 막고, 클릭 반응이 자동 효과음보다 우선하며 랩은 보호합니다.
- 새 캐릭터 음성 여섯 개를 약 0.8~1.4초의 한 번의 발성 중심으로 재편집하고 앞뒤 페이드를 적용했습니다. 전체 음량 50%는 유지합니다.
- 몸집·발 위치의 렌더링 검사, 무작위 크기 방지, 친구 간 음성 중복/우선순위/종료 검증을 추가했습니다.
