# 정보 화면의 여백과 공식 GitHub 마크

- 정보 화면만 520×550으로 넓혀 참고 이미지의 창 비율과 구역 사이 여백을 맞췄어요. 뒤로가기를 누르면 기존 설정창 크기로 돌아와요.
- 안내 문구를 요청하신 내용으로 바꾸고, 첫 문장 뒤의 줄바꿈을 유지했어요. 긴 문장은 창 너비에 맞춰 자연스럽게 이어져요.
- 라이선스 안내는 요청하신 두 줄로 표시하며, 첫 줄을 조금 더 크고 굵게 조정했어요.
- 저장소를 뜻하는 일반 아이콘 대신 GitHub 공식 배포본의 검정·흰색 마크를 적용했어요.
- 링크 버튼 높이와 본문 줄 간격을 넓혔으며, 장식용 그라데이션이나 광택은 추가하지 않았어요.
