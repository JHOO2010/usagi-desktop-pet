# 글라스 말풍선과 화면 모드

- 설정 말풍선에 흐린 배경과 반투명 표면, 가는 테두리를 적용했습니다. 글자와 조작부는 선명하게 유지하며 창 전체의 투명도를 낮추지 않습니다.
- 설정의 **화면 모드 → 라이트 · 다크 · 시스템**에서 선택할 수 있습니다. 선택한 모드는 다음 실행에도 유지하며 모든 친구가 함께 사용합니다. 시스템 모드는 Windows의 앱 밝기 설정을 따릅니다.
- 화면 모드·크기·효과음·시작 시 실행·우사기 랩·업데이트를 같은 기준선과 간격으로 정리했습니다. 업데이트 영역에는 별도 구분선과 여백을 두고, 정보 보기는 하단 중앙에 유지했습니다.
- 캐릭터 선택·정보·변경 내용 화면과 우클릭 메뉴, 일반 말풍선도 같은 밝기 모드를 사용합니다. 정보 링크는 라이트에서 어둡게, 다크에서는 밝게 표시합니다.
- 약 400×430px의 컴팩트한 단일 패널과 12~16px 모서리, 부드러운 베이지 포인트를 적용했습니다. 각 설정은 카드 대신 행으로 나누며, 선택 상태를 베이지로 통일하고, 버튼에 짧은 호버 전환과 키보드 포커스 표시를 적용했습니다. 캐릭터 로고 뒤에 사각형 배경이 남지 않도록 수정했습니다.
- Windows 10/11에서 일관되게 보이도록 **창을 열 때 뒤쪽 화면을 읽어 흐리게 그리는 방식**을 사용합니다. 뒤쪽 영상이 실시간으로 비치는 효과는 아니며 다시 열면 갱신됩니다. 배경 이미지는 메모리에서만 처리하고 저장·업로드하지 않습니다. 캡처할 수 없는 환경에서는 단색 배경으로 표시합니다.
- 라이트·다크·시스템 전환, 열린 하위 페이지의 색상 변경, 텍스트 대비, 설정 저장·복원 및 잘못된 설정의 복구를 검사했습니다.
- 펫 동작·먹거리·음성·설치 호환성은 유지합니다.
