# 앱 내부 업데이트 연결 복구

- 이 PC에서 기존 .NET HTTP 요청이 GitHub 연결 중 시간 초과되는 문제를 확인하고, 업데이트 확인·다운로드에 Windows의 curl 전송을 사용하도록 수정했습니다. 별도 프로그램 설치 없이 숨김 실행하며, curl이 없는 환경에서는 기존 전송을 사용합니다.
- 업데이트 기본 경로 연결에 실패하면 GitHub API 경로도 확인합니다. 두 경로가 모두 실패하면 최신 버전으로 오인하지 않고 재시도 상태를 표시합니다.
- HTTPS·허용된 GitHub 주소·버전별 고정 파일 주소·파일 크기·SHA-256 검증을 유지합니다. 다운로드 진행률과 취소 처리를 연결하고, 중단된 임시 파일은 정리합니다.
- 업데이트 화면에서 연결·다운로드 오류 안내를 표시하고, 진단 로그를 로컬 updates 폴더에 기록합니다.
- 설치 단계에 실행 중인 앱 종료 옵션과 설치 로그를 추가했습니다. 마지막 설치 결과도 남겨 실패 지점을 확인할 수 있습니다.
- 수정된 코드로 실제 GitHub 최신 버전 감지, 설치파일 전체 다운로드 및 체크섬 검증을 확인했습니다.
